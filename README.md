# MiniTask — 軽量タスクマネージャー

Windows 10/11 用の軽量タスクマネージャー。Rust + egui 製。
本家タスクマネージャーの核心機能を、小さな単一 exe で提供します。

![プロセス一覧](docs/screenshot.png)

![パフォーマンス](docs/performance.png)

## 機能

- **プロセス一覧** — タスクマネージャーと同じ既定 7 列:
  名前 / 状態 / CPU / メモリ / ネット受信・送信 / GPU (プロセス別 GPU 使用率)
  - **列見出しを右クリック**して全 14 列から表示列を選択
    (タブバーやタブ内の何もない場所の右クリックでは開かない)
    (PID / I/O / ユーザー / 開始時刻 / パス / コマンドライン など)
  - 列クリックでソート、検索ボックスで絞り込み（名前 / PID / パス / ユーザー）
  - 右クリックメニュー: **タスクの終了 / プロセス ツリーの終了** /
    ファイルの場所を開く / コマンドラインをコピー
  - ダブルクリックでファイルの場所を開く
- **パフォーマンスタブ** — タスクマネージャー (taskmgr.exe) から移植した 3 ペイン構成
  - 左ナビでメトリクス切替: CPU / メモリ / **物理ディスク単位のディスク** /
    **ネットワーク アダプター (イーサネット / Wi-Fi)** / GPU / NPU
    (各項目にミニグラフと名前・種類・値を表示)。
    **接続中のデバイスのみ表示し、切断/非搭載時は自動的に消える**
    (D: と E: のように同じ物理ディスクの複数パーティションは 1 項目に統合)。
    左ナビ・右側の両方が縦スクロール対応
  - 中央: 選択中メトリクスの大きなグラフ (グリッド付き) と詳細情報。
    **縦にはみ出した場合はスクロール可能**
    - CPU: 利用率 / 速度 / プロセス数 / スレッド数 / ハンドル数 / 稼働時間 /
      論理プロセッサ数
    - メモリ: 使用中 / 利用可能 / コミット済み / キャッシュ済み /
      ページ プール / 非ページ プール / 合計
    - ディスク: 本家と同じ 2 段グラフ (上 = アクティブな時間、
      下 = ディスクの転送速度の読み取り/書き込み 2 本線) と
      平均応答時間 / 容量 / フォーマット済み / システム ディスク /
      ページ ファイル / 種類 (SSD (NVMe) / リムーバブル (USB) など)
    - ネットワーク: 送信/受信の 2 本線グラフ (本家と同じ凡例) と
      IPv4 / IPv6 / アダプター名 / 説明 / 帯域幅 / 状態。
      Wi-Fi は wlanapi から SSID と信号の品質も取得
    - GPU: 使用率＋専用 GPU メモリの 2 段グラフ、
      専用/共有 GPU メモリ / モデル / 最も使用された GPU エンジン
    - NPU: 使用率＋専用 NPU メモリ、専用/共有 NPU メモリ
  - **各グラフを右クリック → 「更新の速度」**
    (0.5 秒 / 1 秒 / 一時停止と再開 / **なめらかなアニメーション補間** /
     **スプライン補間** の切替。補間ONでは 250ms ごとの連続サンプリングにより
    更新間隔と無関係に線がシームレスに伸び (時定数 2.5 秒の平滑化付き)、
    60FPS で右端を基準に左へ流れ、左端での消滅も連続。
     スプラインONでは折れ線の代わりに Catmull-Rom 曲線)
  - **CPU グラフを右クリック → 「グラフの変更」で 全体的な使用率 /
    論理プロセッサ (コア別 16 分割グラフ) を切替**
  - **GPU / NPU グラフを右クリック → 「グラフの変更」で全体的な使用率 /
    エンジン種別ごとのグラフを切替** (3D / コピー / ビデオ デコード /
    コンピュート など、本家と同じ PDH GPU Engine / NPU Engine の
    engtype 集計方式。文言も本家リソース準拠)
  - **ディスクの SMART 健康状態** — 健康状態 (百分比) と温度を表示し、
    `SMART 詳細...` ボタンでモデル / シリアル / ファームウェア / 電源投入時間 /
    NVMe の各種ログや ATA 属性一覧 (現在値 / 最悪値 / しきい値 / 生の値) を確認可能。
    NVMe ヘルスログ、ATA SMART、SAT 経由の取得に対応 (非対応時は「取得不可」)
  - グラフの高さはウィンドウサイズに応じて自動調整 (はみ出し防止)
  - GPU 使用率は PDH `GPU Engine` カウンタ、NPU も同じ `GPU Engine` カウンタ
    から取得 (Windows 11 では NPU が Compute Accelerator として同じカウンタに
    載るため、インスタンス名の LUID で GPU/NPU を分離: 3D/Copy/Video 系
    エンジンを持つ LUID = GPU、compute のみの LUID = NPU。本家タスク
    マネージャーと同じ判定)。専用の `NPU Engine` カウンタがある環境では
    そちらを優先する。NPU デバイス自体は SetupAPI (ComputeAccelerator
    クラス) で検出し、カウンタ未提供の環境では「搭載済み (使用率カウンタ
    未提供)」と表示する (`npu_device=true` / `counter=false` の環境でも
    GPU Engine 側から使用率を取得できる)
  - 文言・レイアウトは本家 taskmgr.exe から抽出した日本語リソースに準拠
- **プロセス別ネットワーク使用量** — ETW (Microsoft-Windows-Kernel-Network) による
  リアルタイム計測。TCP/UDP の送受信を PID 別に集計
- **スタートアップ管理** — HKCU/HKLM Run キー・スタートアップフォルダーの
  有効/無効切替（本家と同じ StartupApproved 方式）と削除
- **強制終了** — 確認ダイアログ付き TerminateProcess (設定で確認を省略可能)
- **プログラム アイコン** — プロセスタブとスタートアップタブの名前列に
  実行ファイルのアイコンを表示 (SHGetFileInfo で取得しキャッシュ)
- **設定ダイアログ** — 右上の「⚙ 設定」ボタンから開く
  - **外観**: ダークモード / ホワイトモードと、各モード別の
    プライマリ / セカンダリ / CPU / メモリ / ディスク読取・書込 /
    ネット受信・送信 / GPU / NPU / 警告 / 危険 の配色を個別に変更
  - **グラフと更新**: 更新間隔 (0.5 / 1 / 2 / 5 秒)、アニメーション補間、
    スプライン補間
  - **動作**: 常に手前に表示、起動時のタブ、終了確認ダイアログの表示
  - **システム統合**: Ctrl+Shift+Esc で MiniTask を開く、
    タスクバー右クリックに MiniTask を追加
- **Ctrl+Shift+Esc 置換** — 有効時、右上に純正タスクマネージャーアイコンの
  「タスクマネージャーを開く」ボタンを表示 (ホバーでツールチップ)。
  IFEO (`Image File Execution Options\taskmgr.exe`) で実現
- **タスクバー右クリック「MiniTask」** — explorer への注入で標準メニューを拡張
  (Win10 / クラシックタスクバー)。Win11 の XAML メニューでは拡張できないため、
  右クリック位置に小型ポップアップを表示して起動
- 更新間隔 0.5 / 1 / 2 / 5 秒切替

## 動作要件

- Windows 10 / 11 (x64)
- **管理者権限**（exe マニフェストで要求。起動時に UAC ダイアログが出ます）
  - ETW によるネットワーク計測と、他ユーザープロセスの照会・終了に必要
  - 管理者権限がない場合もプロセス一覧等は動作し、ネットワーク計測のみ無効になります

## ビルド

```powershell
cargo build --release
```

`target/release/minitask.exe` ができます（約 6MB）。

- 日本語表示には Windows 同梱の Meiryo / Yu Gothic / MS Gothic を実行時に読み込みます
- アイコンは `assets/make_icon.ps1` で再生成できます（`#2F9A9A` をアクセントにした
  タスクマネージャー風デザイン）
- タスクバーメニュー注入用の `minitask_hook.dll` も `target/release/` に生成されます。
  この機能を使う場合は **exe と同じフォルダーに dll を配置**してください
  (配置しない場合もポップアップ方式では動作します)

## 使い方

1. `minitask.exe` を実行（UAC を承認）
2. プロセスタブで一覧・ソート・検索。終了したいプロセスを選択して「タスクの終了」
3. スタートアップタブで自動起動アプリの有効/無効・削除

### 開発用オプション（環境変数）

| 変数 | 効果 |
|---|---|
| `MINITASK_SELFTEST=1` | GUI を開かずヘッドレスセルフテストを実行（終了コード 0 = 全合格） |
| `MINITASK_NO_ETW=1` | ETW ネットワーク計測を無効化（非管理者での動作確認用） |
| `MINITASK_MAXIMIZE=1` | 最大化して起動 |
| `MINITASK_SIZE=幅x高さ` | 起動ウィンドウ サイズを指定 (例: `820x480`、検証用) |
| `MINITASK_SPLINE=1` | スプライン補間を有効にして起動 (検証用) |
| `MINITASK_ANIMATION=1` | なめらかアニメーション補間を有効にして起動 (検証用) |
| `MINITASK_TAB=performance` | パフォーマンスタブを開いて起動 (`cpu` / `ram` / `rom` / `gpu` / `npu` / `percore` も指定可) |

## 設定の保存

すべての設定 (更新の速度 / グラフ補間 / 列表示 / ソート / 最後に開いたタブ /
パフォーマンスの選択項目 / CPUグラフモード / テーマと各配色 / 常に手前 /
起動時タブ / 終了確認 / Ctrl+Shift+Esc 置換 / タスクバーメニュー) は
`HKCU\Software\MiniTask` に保存され、再起動後に自動で復元されます
(一時停止は保存対象外)。上記の `MINITASK_*` 環境変数は保存済み設定より
優先されます。

### システム統合の注意

- Ctrl+Shift+Esc 置換は `HKLM\...\Image File Execution Options\taskmgr.exe` の
  `Debugger` 値を変更します (**書き込みには管理者権限が必要**)。
  設定をオフにすると値が削除されます。アンインストール前に必ずオフにしてください。
- explorer への DLL 注入はウイルス対策ソフトに検出される場合があります。
  既定はオフです。Win11 では標準メニューを拡張できないためポップアップ方式になります。
- デスクトップ/フォルダ背景の右クリックにはシェル拡張 (`HKCU\Software\Classes`)
  で「MiniTask」を追加します。

### 管理者権限が必要な確認項目

すべてのコードは非管理者でビルド・単体テスト (`cargo test --workspace`) 可能ですが、
GUI 起動と実機動作確認 (SMART 値、アイコン表示、色変更、IFEO 切替、注入、
`MINITASK_SELFTEST=1`) は `app.manifest` の `requireAdministrator` により
UAC 承認が必要です。ユーザー復帰後に実施してください。

## 技術スタック

| 要素 | 採用技術 |
|---|---|
| GUI | eframe / egui 0.37 (glow バックエンド) + egui_extras テーブル |
| プロセス情報 | sysinfo 0.40 |
| ネットワーク計測 | ETW リアルタイムセッション (windows-sys 0.61) |
| スタートアップ | winreg 0.56 |
| リソース埋め込み | winresource (管理者マニフェスト + アイコン) |

### ネットワーク計測の仕組み

`Microsoft-Windows-Kernel-Network` プロバイダー ({7DD42A49-5329-4832-8DFD-43D979153A88})
のリアルタイム ETW セッションを開き、TcpIp/UdpIp の Send (opcode 10) / Recv (opcode 11)
イベントのペイロード先頭 (u32 PID, u32 size) から PID 別バイト数を累積。
UI 更新ごとに差分をサンプリングして bytes/sec を表示します。
専用スレッドで `ProcessTrace` を実行し、終了時にセッションを停止します。

## 制限事項

- ネットワーク使用量は ETW セッション開始以降の計測です（過去分は遡れません）
- I/O 列はディスク以外の I/O（パイプ・ネットワーク等）も含みます（GetProcessIoCounters 相当）
- 保護プロセス（PPL）の一部情報は取得できない場合があります
